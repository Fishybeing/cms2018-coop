CMS 2018 co-op mod

2. drag everything from this zip into that folder (next to cms2018.exe), replace if it asks
3. start the game. if theres a little "CMS 2018 Co-op" box top left its working

your own save gets backed up while youre in my game and comes back next time you start it.
